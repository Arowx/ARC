# Requests for ARC

A game that needs an engine feature or fix writes one markdown file here, named `<game>-<topic>.md`: what it needs,
why, the API it would like, and an ```arc-check block that should pass once it is done (see `docs/REQUESTS.md`).
Then tell Allan. The ARC session answers it in a release and moves it to `done-notes/` with a "Done in ARC x.y.z" section.

This README keeps the folder in git when no requests are waiting.
